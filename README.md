# RAFT-Ports
RAFT-Ports (Risk Assessment for Tsunamis in Ports) is an open-source application for scenario-based tsunami impact assessment in port environments. Using inundation-depth data and fragility curves, the software estimates the probability of exceedance of (1) structural damage, (2) loss ratio, and (3) production-capacity recovery for port structures.

It is available as standalone Windows and macOS installers. Users do not need MATLAB to run the application, only the free MATLAB Runtime.

Alternatively, RAFT-Ports can be run directly within MATLAB.
