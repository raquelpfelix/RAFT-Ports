# RAFT-Ports
**R**isk **A**ssessment **F**or **T**sunamis in **P**orts **(RAFT-Ports)** is an open-source application that applies fragility and vulnerability functions developed for port structures to estimate **(1) structural-damage exceedance probabilities, (2) expected physical loss, and (3) production-capacity recovery probabilities** for specified tsunami scenarios.

## Installers
It is available as standalone Windows and macOS installers. Users do not need MATLAB to run the application, only the free MATLAB Runtime.

Alternatively, RAFT-Ports can be run directly within MATLAB.

## Disclaimer
The results produced by RAFT-Ports are dependent on the quality of the input data. In particular, uncertainties in inundation-depth datasets, building-footprint data, and the classification of industry types may influence the accuracy of the assessment. Users are encouraged to review and verify all input datasets and the analysis results.
